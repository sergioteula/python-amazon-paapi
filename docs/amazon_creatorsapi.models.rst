Models
======

Every model of the API, re-exported from the generated SDK so they can be imported from
``amazon_creatorsapi.models`` without navigating the SDK structure. The enums listed here
are the ones to use for ``condition``, ``availability``, ``sort_by``, ``resources`` and
the rest of the arguments that only accept a fixed set of values.
